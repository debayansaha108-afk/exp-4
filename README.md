# Experiment 4 – Implement Interactive Basic Views in Android

## 📌 Description

This experiment is developed using Android Studio as part of the Mobile Application Development Lab. It demonstrates the implementation of interactive Android UI components, including Switch, CheckBox, RadioGroup, and SeekBar.

These components allow users to interact with the application by enabling or disabling options, selecting multiple choices, choosing a single option from a group, and adjusting values using a slider.

## 👨‍💻 Author

- **Name:** Debayan Saha
- **Subject:** Mobile Application Development Lab

## 🚀 Features

- Implements an interactive Switch component.
- Uses CheckBox for selecting options.
- Uses RadioGroup for selecting a single option.
- Implements SeekBar for adjusting values.
- Uses XML to design the user interface.
- Handles user interactions through application code.
- Demonstrates basic Android UI development concepts.

## 🛠️ Technologies Used

- Android Studio
- Kotlin / Java, depending on the implementation
- XML
- Android SDK
- Gradle
